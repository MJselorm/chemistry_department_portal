# Chemistry Hub — Frontend Prototype

A multi-page Chemistry Department student platform frontend.

## Pages

Student:
- dashboard.html
- events.html
- event-details.html
- academic.html
- directory.html
- announcements.html
- profile.html
- settings.html

Authentication:
- signin.html
- signup.html
- Google sign-in UI placeholder
- password visibility toggle

Admin:
- admin.html
- admin-events.html
- admin-resources.html
- admin-users.html
- admin-announcements.html

## Run

No build step is required. Open `index.html` directly, or use VS Code Live Server.

## Backend-ready integration points

Authentication, Google OAuth, email verification, password reset, event registration, QR attendance, file uploads, database content, roles/permissions, notifications and audit logs are intentionally represented as frontend integration points.
